# 紅白国旗合戦

国旗を見て正しい国名を選ぶ、2人対戦の早押し4択クイズ(全10問)。

- **この端末で2人**:スマホを2人の間に置いて向かい合って遊ぶ。画面の上半分は向こう側の人用に逆さ表示
- **オンライン対戦**:片方が「部屋をつくる」で4文字の部屋番号を出し、もう片方がその番号(または招待リンク)で参加する

`index.html` 1枚だけで動きます。GitHub Pages で公開すると、アカウントなしでブラウザから遊べます。

## オンライン対戦のしくみ

- 通信は [PeerJS](https://peerjs.com/)(WebRTC)で2台を直接つなぎます。サーバーの用意は不要です
- 部屋をつくった側が審判役で、問題を出して勝敗を判定します
- 回答の速さは各自の端末で「選択肢が押せるようになってから」を測って送るので、遠距離でも通信の遅れは勝敗に影響しません
- 2人とも正解なら速かったほうに1点。相手が正解した時間を自分がすでに過ぎていたら、その問題は締め切りになります
